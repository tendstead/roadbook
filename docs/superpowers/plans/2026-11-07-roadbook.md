# Roadbook Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkboxes for tracking.

**Goal:** Deliver the tested baseline, then a full v1.0 feature PR.
**Architecture:** Standalone embedded SPA/Go API and dedicated PostgreSQL database.
**Tech Stack:** Go, pgx, PostgreSQL, Svelte 5/TypeScript, published @tendstead/ui.
**Spec:** `docs/design.md`.

## Global Constraints

- Signed commits; no sibling modifications; no deployment or release.
- Exact minor-unit money, metres and millilitres; private files excluded.
- Original code uses Elastic-2.0; preserve third-party provenance.
- Unit, isolated service, mobile/desktop e2e, production checks before publication.

## Review Focus

- Interrupted writes/imports: no partially committed domain records.
- Unknown fuel data: no fabricated consumption or silently dropped spending.
- Recurrence retries/month ends: no duplicate or shifted-anchor expenses.
- Profile selection: conditional controls, explicit organizational-only access.
- Attachments: no originals fetched by list views and no path traversal.
